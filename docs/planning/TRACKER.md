# Project Tracker

The single place to see what is done, what is in progress and what comes next. Architecture lives in [ARCHITECTURE.md](../architecture/ARCHITECTURE.md); decisions live in [docs/adr/](../adr/README.md). This file only tracks work.

## How to use this file

**At the start of a session**
1. Read [Now](#now) and the [session log](#session-log) (latest entry first).
2. Open the current milestone's section and pick the first unchecked task whose dependencies are done.

**While working**
- Mark a task in progress by changing `[ ]` to `[~]`. Only one or two tasks should be `[~]` at a time.
- When a task is done, change it to `[x]` and add a short note after `→` if anything is worth remembering (a file path, a surprise, a follow-up).
- New work discovered along the way goes into the right milestone with the next free ID, or into [Backlog](#backlog-after-m7).
- If a decision changes, write or supersede an ADR and update ARCHITECTURE.md in the same change. Do not record decisions here.

**At the end of a session**
- Update [Now](#now) and the milestone status table.
- Add a session-log entry: date, what was done, what is next, open issues.

**Legend:** `[ ]` todo · `[~]` in progress · `[x]` done · `[-]` dropped (say why) · **Deps:** tasks that must be done first.

## Desktop

**Goal:** each agent's computer becomes a light desktop you can watch live: its browser, terminal, files and office apps in windows, not just the browser page. Agents run Python with packages, make Word and Excel files, and use desktop apps.
**Done when:** you watch an agent research on the web, write and run a Python script in its terminal, and save a `.docx` report and an `.xlsx` sheet that open on its desktop and download from the chat; and an agent finishes a task in a desktop app.
**Decided (session 22):** a light desktop, not XFCE (RAM on the 3 GB target); no animated cursor, actions run at full speed and the view shows them; accessibility tree first and screenshots as a fallback, both in this milestone; no paid sandbox (Daytona looked at and set aside).
